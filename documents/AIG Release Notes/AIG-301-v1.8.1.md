# AIG-301 Series v1.8.1 Release Notes

Release Date: Dec 2025

## 📌 Summary
This patch release focuses on stability and connectivity improvements for Azure IoT Edge workloads on AIG-301.

Key highlights include:

- Improved reliability of edgeAgent and edgeHub restart behavior with a watchdog-based monitoring mechanism.
- Added support for environments where the DNS server supports only UDP by providing a configurable DNS UDP-only mode.

## 🛠️ Resolved Issues

- Fixed a condition where edgeAgent and edgeHub could fail to restart properly by introducing a watchdog mechanism that continuously monitors module health and enforces the restart policy.
- Improved DNS compatibility for environments whose DNS servers support only UDP. Containers can now perform DNS lookups successfully through the system DNS proxy when the UDP-only mode is enabled.

### 📥 Installation / Upgrade Notes

**Pre-request**

- AIG-301 Firmware Version: 1.8.0
- ThingsPro Version: 2.6.0-4499

**Upgrade via Web UI**

1. Download the `deb` file from the download link or copy the patch yaml URI.
2. Log in to the Web UI with admin privileges.
3. Navigate to **Maintenance → General Operation → Software Upgrade**.
   1. Select **Upgrade From the Local Drive** with the `deb` file.
   2. Select **Download Over the Air**, input the URI link of patch yaml.
4. (optional) If snapshot-based upgrade is disabled, reboot the device after the upgrade completes.
5. On the Dashboard, confirm that the following versions are shown:
   - Firmware Version: 1.8.1
   - azureiotedge App: 2.4.4-2906

**Additional verification**

> The Dashboard displays the main component versions but does not show the appman package version.
> This patch also updates the appman package, and if you need to verify the appman version specifically, you may check it via console access:
```
dpkg -l | grep appman
```
Expected example:
```
hi appman 2.4.1-3226 armhf App Manager for Moxa ThingsPro Edge
```
> This step is optional and intended for advanced users.
> It is not required for standard upgrade verification.

### ⚙️ DNS UDP-only Support

In environments where the DNS server supports UDP only, you can enable a DNS UDP-only mode so that the system DNS proxy resolves queries using UDP.

Manual configuration (reboot required):
```
sudo sh -c 'echo "APPMAN_DNS_UDP_ONLY=True" >> /etc/environment'
sudo reboot
```

#### 🔄 Restoring the Default Behavior

The DNS UDP-only mode is configured through `/etc/environment`. A configuration reset does not remove this setting.

If you need to revert to the default DNS behavior, you may restore it manually:
```
sudo sed -i '/APPMAN_DNS_UDP_ONLY/d' /etc/environment
```

or simply set it to **False**:
```
sudo sh -c 'echo "APPMAN_DNS_UDP_ONLY=False" >> /etc/environment'
```

A system reboot is required for the change to take effect.
